
# Web-Based Rental Management System

## 1. Project Overview

The Web-Based Rental Management System is a web application designed to help small-scale landlords and property owners manage their rental properties efficiently.

The system provides a centralized platform for managing tenants, rental units, leases, rent payments, maintenance requests and financial records.

It aims to reduce paperwork, improve record keeping and simplify daily rental management activities.

## 2. Project Objectives

- To simplify rental property management.
- To maintain digital tenant records.
- To manage rental units and vacancies.
- To track rent payments and outstanding balances.
- To manage tenancy agreements and lease records.
- To handle maintenance requests.
- To generate financial reports.

## 3. System Features

- User registration and login.
- Landlord and caretaker management.
- Tenant management.
- Property and rental unit management.
- Lease management and printing.
- Rent charging and payment tracking.
- Payment receipts and statements.
- Maintenance request management.
- Vacancy management.
- Financial reports and expenses.
- Notifications and announcements.
- Language support.

## 6. Installation and Setup

1. Install XAMPP on your computer.
2. Clone or download this repository.
3. Place the project folder inside the XAMPP `htdocs` directory.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Open phpMyAdmin.
6. Create a database named `rms`.
7. Import the provided database SQL files as required.
8. Configure the database connection using your local database credentials.
9. Open your browser and visit:

   http://localhost/rms/
